# Release notes: 2026.11

> **DRAFT generated by Claude. A person must review this before it is shared.**

### Bulk reassign loans in the pipeline

Managers can now select multiple loans in the pipeline view and reassign them to another loan officer in one step, without opening each loan. Available to users with the Manager role on Pro and Enterprise plans. No configuration is required.

### Document expiration reminders

Borrower documents such as pay stubs and bank statements now show an expiration date. Loan officers get a reminder 10 days before a document expires so they can request an updated copy. Admins set expiration rules per document type in Settings > Documents. The default is off.

### Borrower portal: upload from phone camera

Borrowers can now take a photo of a document with their phone camera directly from the upload screen in the borrower portal.

### Fix: pipeline summary report totals

We fixed an issue where the pipeline summary report double-counted loans that were reassigned during the month. This affects customers who use the pipeline summary report. No action is required.
